Connect to your GitHub repo

This page saves your trips to trips.yaml in your repo. It needs a GitHub token that works only on that repo. The token stays in this browser and is sent only to GitHub.

How to make the token (2 minutes)
  1. Open GitHub → New fine-grained token.
  2. Under Repository access, choose Only select repositories and pick your flight tracker repo.
  3. Under Permissions → Repository, set Contents: Read and write and Actions: Read and write.
  4. Click Generate token, copy it, and paste it below.
